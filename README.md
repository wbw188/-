这是一个简单的贪吃蛇功能实现代码
该程序实现了一个控制台贪吃蛇游戏，运行于 Windows 系统，使用 conio.h 进行键盘输入检测，通过 Windows API 的 SetConsoleCursorPosition 实现光标定位（gotoxy），从而在原地刷新画面。游戏区域大小为 20 行 × 30 列。
1. 数据结构与全局变量
int a[high][width] = {0};   // 游戏区域二维数组
int move;                   // 当前移动方向：1上 2下 3左 4右
int food_x, food_y;         // 食物坐标
蛇身数值算法：每次移动前所有正数 +1，新蛇头设为 1，未吃到食物时删除数值最大的格子（原蛇尾）。这样数值连续从 1 到 L（L 为蛇长），保证了蛇身顺序。
2. 初始化函数 startup()
设置边界：a[0][j]、a[high-1][j]、a[i][0]、a[i][width-1] 设为 -1。

初始化蛇：蛇头位于 (high/2, width/2)，数值为 1；向左延伸 4 节，数值依次为 2,3,4,5。

初始方向：move = 4（向右）。

随机生成第一个食物：food_x = rand()%(high-5)+2，food_y = rand()%(width-5)+2，并将其设为 -2
3. 显示函数 show()
gotoxy(0,0) 将光标移至左上角，实现原地刷新。
遍历整个 a 数组，根据值打印不同字符：
0 → 空格
-1 → #（墙）
1 → @（蛇头）
>1 → *（蛇身）
-2 → o（食物）
每帧后 Sleep(150)，控制刷新速度。
